Getting started

Up and running

  1. Install and open tri-code. The first launch opens a tour with a sample project, so nothing real runs until you're ready.
  2. Open a project with Alt O. Pick the environment, then type to filter folders.
  3. Start an agent from the + menu. claude or pi need to be installed and on your PATH.
  4. Find anything with the Command Palette, Alt X.
macOS

Opening on macOS

The app is signed but not notarized, so Gatekeeper blocks the first launch. Open System Settings → Privacy & Security and click Open Anyway, or run:

xattr -cr /Applications/tri-code.app
Remote hosts

To run agents over ssh, the host needs key-based ssh that doesn't prompt, and shpool (or tmux) so sessions survive disconnects:

cargo install shpool
