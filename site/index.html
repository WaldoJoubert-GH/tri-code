Your agents, side by side.

tri-code is a minimal agent development environment. Run Claude Code, pi and your shells in tiled windows, on your machine or over ssh, with git, an editor, a browser and your issues one keystroke away.

Features

Everything an agent session needs, nothing it doesn't.

Projects in the sidebar, terminals that keep running, and the tools you reach for between prompts.

Any agent, tiled

claude, pi, a shell or any terminal app you add. Tile them in layouts and spread them over workspaces.

Remote that survives

Projects over ssh attach to shpool or tmux sessions, so agents keep working through dropped connections and restarts.

Agent signals

See which agents are working, waiting for you, done or failed. Get a sound and a notification, then jump to the next one with Alt U.

Worktrees built in

One branch per agent. New worktree makes the checkout, opens an agent in it, and cleans up when the PR merges.

Git with drafts

Stage, diff unified or split, commit, push, open and merge PRs. ✦ drafts the commit message, PR and a branch review with the command you set for each in Settings › Git, Claude Code by default.

A real editor

File tree, tabs and CodeMirror with search, multi-cursor and folding. A Diff view against HEAD, and saves that won't clobber an agent's edits.

Browser that points

Browser windows with pages and profiles. Select an element, describe the change, and it goes to your agent with its selector, styles and source file.

Issues next to the code

Plane, GitHub Issues and local issues in one keyboard-driven panel, linked to the branch you're on.

Keyboard first

A Command Palette for everything (Alt X), fuzzy Go to File, and every hotkey rebindable.

Layouts

Run the whole team at once

claude, pi, the issues panel and a shell in one grid. Projects are grouped by where they run: your machine or any ssh host.

  • Minimise a window without stopping it
  • Four workspaces per project
  • Accent colours and icons per project
Git

Review what the agent did

Read the diff, stage what you want, and let ✦ write the commit message from the diff, the issue in progress and your commit style.

  • Push, open a PR and merge from one window
  • PR checks refresh while they run
  • Branch status always in the status line
Editor

Make the small fix yourself

Open any file in a tab, see Markdown, HTML and SVG rendered, and switch to a diff of your unsaved edits with Alt D.

Free, open source, and ready in a minute.

The first launch opens a short tour with a sample project, so you can try everything before pointing it at your own code.
