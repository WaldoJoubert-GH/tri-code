Your agents, side by side.

tri-code is a minimal agent development environment. Run Claude Code, pi and your shells in tiled windows, on your machine or over ssh, with worktrees, git, an editor, your database and your issues one keystroke away.

Features

Everything an agent session needs, nothing it doesn't.

Projects in the sidebar, terminals that keep running, and the tools you reach for between prompts.

Any agent, tiled

claude, pi, a shell or any terminal app you add. Tile them in layouts and spread them over workspaces.

Remote that survives

Projects over ssh attach to shpool or tmux sessions, so agents keep working through dropped connections and restarts.

Agent signals

See which agents are working, waiting for you, done or failed. Get a sound and a notification, then jump to the next one with Alt U.

Worktrees built in

One branch per agent. New worktree adds your branch prefix, runs a setup script once, opens the agents you pick and cleans up when the PR merges. Pin the ones you're working on.

Git with drafts

Stage, diff unified or split, commit, push, open and merge PRs. ✦ drafts the commit message, PR and a branch review with the command you set for each in Settings › Git, Claude Code by default.

A real editor

File tree, tabs and CodeMirror with search, multi-cursor and folding. A Diff view against HEAD, and saves that won't clobber an agent's edits.

Browser that points

Browser windows with pages and profiles. Select an element, describe the change, and it goes to your agent with its selector, styles and source file.

Issues next to the code

Plane, GitHub Issues and local issues in one keyboard-driven panel, linked to the branch you're on.

Your database, beside the code

Browse and edit Postgres, SQLite and MongoDB. Edits apply in one checked transaction, read-only connections stay read-only, and ssh projects tunnel through the host.

Agents drive windows

A bundled MCP server lets claude and pi start a command you allowed, read its terminal, type into it and wait for it to finish.

Remote Control

Your agents on your phone over Tailscale: watch a terminal live, type into it, and get a push when one needs you.

Keyboard first

One box finds commands and files together (Alt X), and every hotkey is rebindable.

Layouts

Run the whole team at once

claude, pi, the issues panel and a shell in one grid. Projects are grouped by where they run, your machine or any ssh host, with their worktrees beneath them.

  • Minimise a window without stopping it
  • Four workspaces per project
  • Badges show which agents are working, waiting or done
Git

Review what the agent did

Read the diff unified or split, stage what you want, and let ✦ write the commit message from the diff, the issue in progress and your commit style.

  • Push, open a PR and merge from one window
  • PR checks refresh while they run
  • Branch status always in the status line
Editor

Make the small fix yourself

A file tree that shows git status, a tab per file and CodeMirror with search, multi-cursor and folding. Switch to a diff against HEAD with Alt D.

Database

Check the data the agent touched

Open a project's Postgres, SQLite or MongoDB from the Command Palette. Filter with a WHERE, sort, page, and edit rows in place.

  • Connections saved per project, passwords kept on its host
  • Pending edits apply in one transaction, each checking its row
  • Query and Structure tabs beside the data
Commands

Every tool you start, in one list

claude, pi, a dev server, lazygit or a web app. Give each an icon, a hotkey and its own sounds, and offer it everywhere, on one environment or in one repo.

  • Several lines run one after another in a login shell
  • The Agent toggle lets your agents open it themselves
  • Web apps open a browser window at their address
Command Palette

One box for everything

Alt X finds commands and files together, commands first, with their hotkeys beside them. / browses the project's folders.

Free, open source, and ready in a minute.

The first launch opens a short tour with a sample project, so you can try everything before pointing it at your own code.
